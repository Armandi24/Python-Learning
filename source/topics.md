# Topics — starter bank

Pull from here during `prep`. Mark items done or note which milestone they map to as
you go; add new ones as real scripts/needs come up (this is meant to grow, not stay
fixed).

1. Print a few personal values (name, a number, a sentence) — first script, milestone 1
2. Simple calculator: take two numbers, do +/-/*/÷ — milestone 1
3. "Is this number even or odd" — milestone 2
4. Grade checker: given a score, print a letter grade with `if`/`elif`/`else` —
   milestone 2
5. Print numbers 1-10, then only even ones, using `for` and `range` — milestone 3
6. Simple countdown using `while` — milestone 3
7. Build a shopping list as a `list`, add/remove/print items — milestone 4
8. Sum and average of a list of numbers — milestone 4
9. Function that converts Celsius to Fahrenheit, called with a few different inputs —
   milestone 5
10. Take a short (10-15 line) script Claude wrote for something unrelated, trace what
    it does line by line without running it — milestone 6
11. Take that same script and change one constant/size/string, predict the outcome,
    then run it — milestone 7
12. Small personal script: something from Grasshopper/AutoLISP-adjacent work reimagined
    in plain Python (e.g. generate a simple sequence of numbers, or a naming pattern for
    files) — milestone 9
