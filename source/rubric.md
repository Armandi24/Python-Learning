# Rubric — Python milestone/project assessment (Type 4)

Used during `assess`. Score 1-5 on each dimension that's relevant to the milestone
being tested (not every dimension applies to every milestone). ≥4/5 on every applicable
dimension = mastery gate passed, safe to advance.

1. **Syntax correctness** — indentation, colons, parentheses, no typo-level errors.
2. **Reads unfamiliar code** — can trace what an unseen small script does, out loud or
   in writing, before running it.
3. **Predicts edit outcomes** — before running an edited script, correctly predicts
   what will change.
4. **Debugs independently** — reads the actual error message and locates the problem
   line without being told.
5. **Uses the right construct for the task** — picks `for` vs `while`, list vs dict,
   etc. appropriately rather than forcing one tool everywhere.
6. **Writes from a task description** — given a plain-English task, produces a short
   working script unaided.

## Format

`date | milestone | dimension | score | note`

2026-08-26 | 1 | syntax correctness | 3 | quoted-string, hyphen-in-name, mismatched-name errors, all self-fixed after error msg
2026-08-26 | 1 | predicts edit outcomes | 2 | predicted appleperbag=3.0, missed that a 2nd assignment (//) overwrote the 1st (/)
2026-08-26 | 1 | debugs independently | 4 | read tracebacks and fixed correctly once told to paste the actual error
2026-08-26 | 1 | writes from task description | 3 | completed unaided but with multiple real errors along the way

**Gate: not passed (below 4/5 on 2 dimensions) — stay on milestone 1 one more session, focus on reassignment/prediction**
